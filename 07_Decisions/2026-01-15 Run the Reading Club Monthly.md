# Run the Reading Club Monthly

## Decision

If the pilot continues, run it monthly rather than weekly for the first three sessions.

## Context

The goal is to test whether the gathering creates useful connection without making it burdensome to host.

## Rationale

Monthly sessions leave enough time to read and organize while still creating continuity.

## Alternatives

- Weekly: stronger rhythm, but too much initial coordination.
- One-off only: lowest overhead, but no chance to test continuity.

## Review

Review after the pilot and again after three sessions. Change the cadence if participant feedback supports it.
