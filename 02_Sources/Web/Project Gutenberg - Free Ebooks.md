# Project Gutenberg - Free Ebooks

> Example source note. Check the live site before relying on details.

## Original

[Project Gutenberg](https://www.gutenberg.org/) is a library of free electronic books, with a focus on older works whose U.S. copyright has expired.

## Extracted Signals

- A reading group could choose a public-domain text to reduce cost and access friction.
- Copyright status varies by country; participants should verify what they may download where they live.
- The project should link to the original book page rather than redistribute a file without checking its terms.
