# Obsidian Setup

1. Check whether the user already has Obsidian and whether this folder is already open as a vault.
2. If not installed, direct the user to the official download at <https://obsidian.md/download> or offer to install only with explicit approval.
3. In Obsidian, choose **Open folder as vault** and select this repository root.
4. Confirm that Templates points to `90_System/Templates` and Daily Notes uses `01_Journal` with `90_System/Templates/Journal.md`. Starter configuration is already present under `.obsidian/`.
5. Open `Home.md` and verify wiki links resolve.
6. Avoid community plugins during onboarding. Add one only to solve an observed need and review its permissions first.

Obsidian is optional. Do not frame it as required for agents or Git sync.
